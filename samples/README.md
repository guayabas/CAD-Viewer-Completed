# Samples

Test CAD files. Everything here is git-ignored except this README and the one small STEP file below, which the Rails job tests use as input.

| File | What it is | Size |
|---|---|---|

## Source and license

From the NIST MBE PMI Validation and Conformance Testing project (the NIST CAD test models with product manufacturing information). Works of the U.S. government (NIST) are not subject to copyright in the United States, so these files are public domain there.

The viewer's default model, `viewer/public/nist_ctc_01_asme1_ap242-e1.glb`, is this file run through the tessellator.
